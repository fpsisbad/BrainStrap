# BrainStrap

A Roblox launcher by rblx.brain. Source is in [`BrainStrap/`](BrainStrap/) (see its [README](BrainStrap/README.md)).

**Download:** the newest build is always at
`https://github.com/fpsisbad/BrainStrap/releases/latest/download/BrainStrap.exe`

Builds are made by GitHub Actions (`.github/workflows/build.yml`): Actions → Build BrainStrap → Run workflow, or push a tag like `v2.0.0`.

BrainStrap is an independent project. It is not made, endorsed or sponsored by Roblox Corporation.
